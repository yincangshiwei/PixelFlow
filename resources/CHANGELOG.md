# PixelFlow 版本日志

## 2026-08-05

### 配置中心 — 创建环境自动安装 CUDA/CPU 版 PyTorch

- 「创建/修复环境」「强制重建」会通过 `nvidia-smi` 检测本机 NVIDIA，有独显时从 PyTorch 官方索引安装 CUDA 版 torch，否则安装 CPU 版
- CUDA 版安装失败时自动回退 CPU 版，保证环境仍可推理；一份 CUDA 版即可，配置里仍可强制用 CPU
- 配置页环境状态展示 torch 版本与构建类型（CUDA/CPU）；开发环境诊断增加 GPU 检测与安装策略说明
- 按 GPU 计算能力选择 CUDA 标签：RTX 50 系（Blackwell / sm_120）优先 cu132/cu130/cu129，避免 `no kernel image`；安装后校验 wheel 是否含本机架构，不匹配则自动换更高标签

### 配置中心 — 主流 GPU 匹配清单与 AI 帮装

- 新增主流系列匹配清单（RTX 50/40/30/20、GTX 16/10 等）：优选与备选 CUDA 标签、驱动门槛、系列说明
- 抠图模型环境区展示「GPU 匹配」摘要；驱动不足时创建环境前提示升级，并可跳转驱动下载页
- 增加「AI 帮装」按钮：弹窗生成可复制任务说明；正文为通用流程（复核环境、查官网选 CUDA、安装验收），不写死某代显卡；附录附本机探测快照与内置清单供参考

### 配置中心 — VC++ 运行库检测与环境失败提示

- 在「抠图模型」推理设备旁增加一行简短最低配置提示
- 切换 CPU / CUDA / 自动时按当前设备显示对应要求（如 CPU：最低内存 8GB；GPU：建议显存 4GB），不同时展示两套说明

### AI 抠图 — 读图/推理/后处理流水线（阶段3性能优化）

- 开启 AI 抠图且处理多张时，读图预取、模型推理、trim/画布/保存三阶段并行重叠
- 推理仍串行使用常驻模型，预取与后处理队列深度受限，控制内存峰值
- 后台日志输出流水线启用状态，以及每批推理/后处理耗时
- 流水线异常时自动回退到原有串行 micro-batch 路径

### AI 抠图 — GPU 自适应 micro-batch（阶段2性能优化）

- 未开边缘精炼且使用 GPU 时，按显存自动选择 batch 1~3，多张图一次 tensor 推理
- 显存不足（OOM）时自动降半重试，并记住本会话上限，避免反复撑爆
- CPU 模式与「边缘精炼」仍逐张处理，保证稳定与边缘质量
- 后台日志：启动时输出模型/设备/micro-batch；每批显示 batch 序号与文件范围；完成行带 batch 与设备

### AI 抠图 — 预缩放推理 + 仅回传遮罩（阶段1性能优化）

- 未开边缘精炼时：大图先按 BEN2 同等方式缩至 1024×1024 再送模型，worker 只返回单通道遮罩，主进程放大后贴回原图像素
- 原图 RGB 不经 AI 管线重编码，网络输入与原先全尺寸路径等价，遮罩精度保持同级
- 开启边缘精炼时仍走全尺寸 RGBA，保证发丝/边缘色估计质量
- 大图批量时可明显降低临时文件体积与读写开销

### 透明图处理 — 画布布局按智能对象方式一次栅格化

- 主体以裁剪后的全分辨率作为源，布局只记录画布与占比参数，导出时再采样合成
- RGBA 预乘 Alpha 后重采样，减轻半透明边缘发灰、发虚
- 按缩小/放大幅度自动选择重采样算法，并提供标准/弱/关闭三档细节恢复（默认标准）
- 始终按主体占比缩放（含小图放大），保证批量标准化构图；已移除「低分辨率不放大」
- 界面说明：画布小于源时会丢细节；源本身偏小时放大也无法凭空变清

### 透明图处理 — 调整尺寸与画布合并为主体占比布局

- 合并「调整尺寸」和「放置到画布」，改为通过主体占画布百分比统一控制视觉大小
- 方形、横向和竖向画布均按比例生成安全框，主体保持原始宽高比并完整居中显示
- 主体从裁剪后的原始分辨率直接执行一次最终缩放，避免中间尺寸转换造成重复质量损失
- 默认透明画布并提供「低分辨率主体不放大」，旧版预设会自动迁移为近似占比

### 透明图处理 — 提升缩放后的细节清晰度

- 调整尺寸采用高质量单次重采样，并针对缩小结果适度恢复纹理与轮廓细节，减少画面发软
- 透明通道独立保留，不对抠图 Alpha 边缘过度锐化
- 修正放置画布时的透明合成，避免半透明边缘重复衰减而显得模糊

### 透明图处理 — 修复 AI 抠图完成后软件异常退出

- 完成提示改为在后台处理线程和 AI 子进程完全清理后显示，避免任务成功后界面卡住并异常退出
- 处理参数在启动时完整快照，后台线程不再访问界面控件，提升组合处理稳定性

### 批处理 — 支持继续未完成 / 重试失败

- 逐文件任务取消或中途失败后，可用「继续」从剩余文件接着跑，或「重试失败」只重跑失败项
- 「继续」仅在用户取消后出现，「重试失败」仅在有失败项时出现；取消弹窗不再提供续跑操作
- 参数与输出设置默认沿用该批次快照
- 左侧列表用 ✓/✗/⏸ 标记成功、失败、取消未完成；支持「选中失败项」
- 图片排版导出等批量合并功能仍整批处理，不支持按文件续跑

### 透明图处理 — AI 抠图常驻 worker，批量明显加速

- 批量 AI 抠图时模型只加载一次，后续图片复用同一子进程推理，避免每张重新 import torch 与加载权重
- 任务结束或取消后自动关闭常驻进程，释放 GPU/内存
- 兼容保留单次子进程模式作为回退

### 透明图处理 — 修复批量 AI 抠图中途误报环境未就绪

- 批量抠图时不再对每张图强制完整依赖检测，避免反复加载 torch 导致超时后误报「环境未就绪」
- 同一进程内同一模型仅首次校验环境；依赖探测超时/异常不再当成缺包
- 仅在 worker 真实报导入失败时才清除就绪标记并重新检测

### 后台日志 — 处理开始/结束时间与耗时

- 点击「开始处理」后记录开始时间；任务结束时输出结束时间与总耗时（秒，长任务附带分/小时）
- 完成弹窗同步显示本次耗时，便于对照进度条以外的实际花费

### 透明图处理 — 裁剪透明边缘更稳健

- 裁剪时按主体连续区域识别内容，忽略 AI 抠图残留的断裂半透明噪点
- 避免上下（或左右）已贴边时，对侧大片空白仍裁不掉的问题；横图、竖图同样适用

### 配置 / 后台日志 — 环境与模型配置过程写入日志

- 安装 uv、创建/修复模型隔离环境、下载模型权重时，进度与结果会写入「后台日志」，不再只有进度条
- 长任务开始时自动切换到后台日志页，便于查看详细阶段信息

### 配置 — 模型配置依赖开发环境门禁

- 开发环境（Python / uv）未就绪时，「抠图模型配置」右侧仅显示引导与「前往开发环境配置」按钮
- 开发环境就绪后自动展示完整模型配置内容

### 透明图处理 — AI 抠图就绪检查与配置跳转

- 切换 AI 抠图模型时按该模型独立检查开发环境、隔离环境与权重状态
- 未配置时提示区提供可点击链接，可直接跳转到「开发环境」或「抠图模型配置」
- 从配置页返回图像处理时自动刷新就绪状态

## 2026-05-08
